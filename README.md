# Advoc8 custom contact details

[Open the prototype](https://regoke.github.io/Custom-details-2/)

Albanese profile matching the latest annotated Figma contact-details flow, including close controls in modal headers.

`index.html` is the self-contained published website. Download and unzip `source.zip` for the editable HTML, CSS, JavaScript and assets. Run that source with `python3 -m http.server 8000`.

Sample contacts are browser-only and reset on refresh. Private team notes are replaced with neutral sample content. No production records are changed.
